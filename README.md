# سامانه مدیریت ثبت‌نام و پیگیری صدور مجوز صنایع دستی

## 📝 شرح پروژه
سامانه‌ای تحت وب مختص کافی‌نت برای مدیریت فرآیند درخواست مجوز صنایع دستی.
شامل ثبت‌نام چندمرحله‌ای، بارگذاری مدارک، پیگیری با کد رهگیری، پنل مدیریت،
لغو خودکار درخواست‌های منقضی شده و گزارش‌گیری.

## 🛠️ فناوری‌ها
- PHP 8 خالص (بدون فریم‌ورک)
- معماری MVC دست‌نویس
- MySQL/MariaDB با PDO
- Bootstrap 5

## 🚀 نصب و راه‌اندازی

### ۱. پیش‌نیازها
- PHP 8.0+
- MySQL 5.7+ یا MariaDB 10.3+
- Apache با mod_rewrite فعال

### ۲. نصب
1. فایل‌ها را در پوشه `htdocs` (XAMPP) یا `www` (Laragon) کپی کنید.
2. پایگاه داده `handicraft_license` را با اجرای فایل `database/schema.sql` ایجاد کنید.
3. تنظیمات `config/config.php` را مطابق محیط خود ویرایش کنید.
4. رمز عبور مدیر پیش‌فرض را با `password_hash` تولید و در SQL جایگزین کنید.

### ۳. اجرا در لوکال
- آدرس `http://localhost/` را در مرورگر باز کنید.
- برای ورود به پنل مدیریت: `http://localhost/admin/login`
- نام کاربری: `admin` | رمز عبور: `admin123`

### ۴. انتقال به سرور
1. فایل‌ها را در public_html آپلود کنید.
2. `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASS` را به‌روز کنید.
3. `BASE_URL` را روی `/` یا زیرمسیر مناسب تنظیم کنید.
4. مجوز پوشه `uploads` را روی `755` تنظیم کنید.
